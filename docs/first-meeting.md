# First meeting: leave with one reproducible contribution

Suggested 60-minute session. Bring a computer with Python 3.11+ and a copy of this repository. No electronics are required.

1. **10 minutes — Orient.** Read the README and name one question the club could answer this term. Separate interests from demonstrated capabilities.
2. **15 minutes — Run.** Execute the tests, record the real output, and inspect `test_statistics_and_gap_boundary`. Identify why the inputs are artificial and why they cannot support a hardware claim.
3. **15 minutes — Review.** In pairs, trace how a repeated timestamp reaches a useful error. Propose a small improvement with a reproducible failing case; do not change code solely to make a number of tests larger.
4. **15 minutes — Propose.** Draft one project brief with a falsifiable success criterion and a list of missing resources. Do not buy hardware yet.
5. **5 minutes — Handover.** Assign one small issue, a reviewer, and a next meeting. Keep names and contact details in the school's approved private channel unless publication is agreed.

A good first PR might clarify a confusing error message with its regression test, document an actual installation issue, or add a verified boundary case. Contributors do not need a flight project to do valuable engineering.
