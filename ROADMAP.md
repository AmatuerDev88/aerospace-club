# Next useful work

This is a sequence of proposed work, not a list of promised flight capabilities.

| Order | Deliverable | Done when |
| --- | --- | --- |
| 1 | Club ownership and review practice | Two maintainers can reproduce tests; faculty sponsor and private contact route agreed; repository review settings configured |
| 2 | First project decision | One reviewed brief and decision record specify a measurable goal, resources, uncertainty, and supervision |
| 3 | First real bench record | Approved experiment has preserved raw data, calibration status, manifest, reproduction commands, and an honest criterion disposition |
| 4 | Device-specific importer | A chosen device's documented export is converted with explicit time/units; original bytes are preserved and edge cases tested |
| 5 | Analysis suited to that experiment | Plots or models answer its question, include units and uncertainty, and can be regenerated |

Defer radio protocols, flight software, autonomy, vehicle simulation, and hardware design until a selected project provides requirements and verification cases. For simulations, start with analytically checkable limiting cases and a documented validity range.

At the end of each term, archive what was actually built, failed, learned, and left unresolved. Have a new member follow the setup instructions without coaching before accepting the handover.
